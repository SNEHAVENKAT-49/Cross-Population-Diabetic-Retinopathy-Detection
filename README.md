# Cross Population Validation of Deep Learning Models for Diabetic Retinopathy Detection

## Abstract
Diabetic Retinopathy (DR) is one of the leading causes of vision loss among diabetic patients. This project focuses on evaluating the performance of deep learning models across Indian and Western retinal image datasets. The objective is to analyze how well a model trained on one population generalizes to another and identify challenges in cross-population diabetic retinopathy detection.

---

## Objectives
- Detect diabetic retinopathy using deep learning techniques.
- Compare model performance on Indian and Western retinal datasets.
- Improve the generalization capability of the model across different populations.
- Evaluate model performance using standard evaluation metrics.
